## Install on Windows

1. Prefer the Setup EXE for a regular installation with shortcuts. Use the Portable EXE to run without installing.
2. Windows may show a SmartScreen warning because the installer is not code-signed. Only run it if you downloaded it from this official repository.
3. Local profiles store progress on that installation/device. Export a backup before moving between installations.

## Install on Android

1. Download the APK on your Android phone.
2. Open it, permit installation from that browser/file manager when Android asks, and tap Install.
3. Open the app from your launcher. The game and local profile features are bundled; network-backed accounts and social features still require a configured cloud backend.

The directly downloadable APK is debug-signed to enable straightforward sideload installation. It is not a Play Store release. Since the debug signing key is generated by the build runner, a future APK may not install over this first build; export your progress first, then uninstall the old APK before installing a differently signed update. A private, persistent release keystore is required for seamless signed updates and Play Store publishing.

The download links resolve only after GitHub Actions has built the Windows installer/portable app and Android APK and published them as release assets. The repository CI and mobile/desktop build jobs must pass first.
