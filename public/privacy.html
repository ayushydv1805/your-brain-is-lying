PRIVACY & DATA

Your practice is yours.

This notice explains how Your Brain Is Lying handles information in local-profile mode and in optional cloud mode. The app's brain-game scores are practice metrics, not medical or formal intelligence assessments.

1. Local profiles

Without cloud configuration, profile details and game progress are stored in your browser's local storage on the device you are using. This can include a display name, email label for the local profile, XP, level, personal bests, activity dates, achievements and saved run summaries.

Local profiles do not sync to other devices. Clearing browser/site data may remove them. Use the app's backup feature before clearing data or changing devices.

2. Optional cloud accounts

When the operator configures Supabase and you choose cloud sign-up, Supabase Auth processes your email address and account credentials. The app stores a public player handle, display name, optional avatar choice, and a saved progress snapshot in the connected database. The snapshot can include game summaries, scores, streaks and achievements.

Cloud progress is associated with your account and is intended to be available across devices. It requires an internet connection. Supabase processes the information under its own service terms and privacy policy.

3. Friends, challenges and leaderboards

  • Friend requests and challenges record the participating accounts, status, skill and timestamps.
  • Player handles and display names are visible to signed-in players so they can find one another.
  • Publishing a score to a leaderboard is opt-in and is off by default. If enabled, the selected handle/avatar and submitted score may appear in that ranking.
  • Leaderboard scores are submitted by the browser and are intended for friendly competition only.

4. Shared Brain Passport links

When you create and share a Brain Passport link, the selected summary is placed in the link itself. Anyone who gets that link may be able to view the summary. The link is designed not to contain your raw run history or individual test answers. Review a passport before sharing it.

5. Tracking, sharing and security

The app does not include an advertising or analytics SDK and does not send game results to a generative-AI service. Hosting, authentication, database and network providers may process technical data needed to deliver their services. Do not put secrets in profile names or public handles.

Only configure the browser app with a Supabase publishable/anonymous client key. A Supabase service-role key must never be placed in a browser build. Database access depends on the Row Level Security policies supplied with this project.

6. Retention and deletion

Local data remains in your browser until you delete it or the browser removes it. Backups are files you control. Cloud data remains in the configured database until the project operator deletes it; this app currently has no self-service cloud account deletion button.

For an account/data removal request, contact the project maintainer via the project repository. Do not publish passwords, email addresses or other private account details in a public issue. The operator should verify a request before deleting account data.

7. Choices and questions

You can use the app in local mode without setting up a cloud account. In cloud mode, leaderboard publishing is optional. You can sign out or stop using the app at any time; signing out alone does not erase cloud data already stored for the account.

This is the project's current practical privacy notice, not legal advice. A public launch operator should review it against the actual deployment, hosting settings and applicable requirements.
